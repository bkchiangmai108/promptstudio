## Variant: Editorial Library

### Design stance
Content คือพระเอก — ให้ prompt อ่านเหมือนบทความคุณภาพ แบบ Notion/Medium สาย editorial

### Key choices
- Layout: asymmetric hero (ซ้าย sticky pitch / ขวา list "prompt ยอดนิยม" สไตล์นิตยสาร)
- Typography: IBM Plex Serif หัวข้อ + Plex Sans Thai เนื้อหา + Plex Mono เมตา
- Color: ครีมอุ่น #fbfaf7 + ink + accent ส้มอิฐ #c2410c
- Interaction: ค้นหาแบบเรียลไทม์ + กรองหมวด + featured list hover slide + modal

### Trade-offs
- Strong at: ความน่าเชื่อถือ อ่านสบาย แยกจากเว็บ AI ทั่วไปชัดสุด, ขาย "คุณภาพของ content" ได้
- Weak at: ความ "ว้าว" ด้าน motion น้อยกว่าสองตัวแรก

### Best for
คนทั่วไป + มืออาชีพที่มาหา prompt คุณภาพ (กลุ่ม A+B) — ตรง audience สุด
