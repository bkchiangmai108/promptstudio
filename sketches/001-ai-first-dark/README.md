## Variant: AI-First Dark

### Design stance
AI tool ต้องดู high-tech ทันที — dark + gradient สไตล์ Linear/Vercel, Generator เป็นพระเอกกลางจอ

### Key choices
- Layout: hero กลางจอ → generator เต็มความกว้าง → library grid 3 คอลัมน์
- Typography: IBM Plex Sans Thai + JetBrains Mono สำหรับตัวเลข/prompt output
- Color: near-black #0a0a12 + gradient ม่วง→teal (#7c5cff→#00e0c6)
- Interaction: typewriter effect ตอน generate, count-up stats, modal preview, glow ambient

### Trade-offs
- Strong at: ความรู้สึก "เครื่องมือมืออาชีพ" ขายฝีมือ tech ได้เลย
- Weak at: อ่าน content ยาวๆ ใน dark mode เหนื่อยกว่า, ใกล้เคียงเว็บ AI เจนๆ มาก

### Best for
สาย prompt engineer / dev ที่อยากเห็นความเป็น tool จริงจัง
