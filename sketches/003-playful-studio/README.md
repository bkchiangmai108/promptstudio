## Variant: Playful Studio

### Design stance
เว็บนี้คือ playground — motion จัดเต็ม สอนผ่านการเล่น โชว์ฝีมือ interactive design

### Key choices
- Layout: split-pane workspace (ซ้ายเลือก/ขวาประกอบ prompt) + lesson slider + marquee cards
- Typography: Noto Sans Thai หนา 900 + Space Grotesk display
- Color: deep purple #14121f + 4 สี neon (pink/purple/yellow/mint)
- Interaction: word rotator, floating blobs, draggable "prompt strength" slider (สอน R-C-T-F), quiz ตอบถูก/ผิด, marquee pause-on-hover, ปุ่มสุ่ม

### Trade-offs
- Strong at: สนุก น่าจำ โชว์ skill ด้าน interactive ชัดสุด, ตรงโจทย์ "interactive animation webapp"
- Weak at: เสี่ยงดู "สนุกเกิน" สำหรับมืออาชีพบางกลุ่ม, ตัวหนังสือเยอะบนพื้น neon ต้องระวัง readability

### Best for
โชว์ portfolio ด้าน interactive + กลุ่มผู้เรียน (เรียนรู้ผ่านการเล่น)
