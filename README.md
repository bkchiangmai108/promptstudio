# Prompt Studio

Thai-first Prompt Library & Generator — คลัง 99 prompts ครบ 6 กลุ่มอุตสาหกรรม

## Features
- **Prompt Generator** — เลือกอุตสาหกรรม → บทบาท → เป้าหมาย ได้ prompt พร้อมใช้
- **Library** — 99 prompts ครบ ธุรกิจ / การตลาด / สุขภาพ / การศึกษา / เทค-IT / สร้างสรรค์
- **Image & Video Prompt** — 14 สไตล์ภาพ + แปลงเป็น video prompt (Sora/Runway/Kling/Veo) + แนบภาพอ้างอิง
- **Interactive Lessons** — slider สอนโครงสร้าง prompt แบบ R-C-T-F-E
- **Member System** — Light/Dark mode, pricing ฿99 เดือนแรก / ฿790 ปีแรก

## Tech
Static HTML/CSS/JS — no build step, no backend. Deploy anywhere (Vercel/Netlify).

## Structure
- `index.html` — production app (single file)
- `v2-refined/` — same app (source of truth during development)
- `sketches/` — design variants history
